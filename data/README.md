
# Dataset Information

This project uses three datasets provided by TripleTen as part of the Data Analytics program.

The original CSV files are not included in this repository.

## Required Datasets

| File | Description |
|---|---|
| `visits_log_us.csv` | Contains user visit and session records. |
| `orders_log_us.csv` | Contains customer purchase and order records. |
| `costs_us.csv` | Contains marketing expenses by advertising source and date. |

## How to Use the Data

To reproduce the analysis, place the three original CSV files in this `data/` directory.

The datasets must retain their original filenames.

**Note:** The datasets were provided by TripleTen for educational purposes and are not redistributed in this repository.
